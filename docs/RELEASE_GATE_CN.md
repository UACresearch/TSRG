# TSRG 下载版发布门槛（私有候选包）

本文件区分**可供授权合作者验证的精简程序 ZIP**与**将整个 GitHub 仓库设为 Public**这两件事。当前主仓库保存了 R18—R20 原始 Notebook、模型实验记录与预测明细，因此正式公开整个仓库需要逐项审查历史文件和 Git 提交记录。下载包使用明确白名单，仅保留独立推理所需的自有程序与说明，并不自动改变整个仓库的可见性。

## 正式公开前仍须核实

- [ ] 确认所有研究成员对署名、公开内容及各自贡献的授权。
- [ ] 审核本仓库历史文件和提交记录中的个人信息、外部数据、图片元数据、密钥及第三方代码授权。整个仓库设为 Public 会暴露完整历史，而不只是下载包。
- [ ] 核实发布者对 R19 训练适配器的分发权；基础模型权重继续指向官方来源。若无法公开适配器，需要说明访问申请或保留研究合作者使用模式。
- [ ] 确认上游 S-Lab License 1.0 非商业使用、版权声明以及其他依赖的授权条款；不要把第三方许可写成本项目自行许可。
- [ ] 根据运行环境补充已验证的系统要求，避免未经验证地宣称支持普通笔记本、单 GPU 或自动旅游场景识别。
- [ ] 若希望用户直接下载运行图片生成功能，另行集成该功能并完成独立测试；当前下载版仅支持相机参数估计。

## 当前建议的交付方式

1. 使用 `python tools/build_download_zip.py` 生成 `dist/TSRG-inference-v0.1.0-rc1.zip`，或下载本私有分支 GitHub Actions 的同名 Artifact（通常有保留期限）。
2. 经授权的合作者从官方取得基础模型权重，并通过私有归档取得经校验的 R19 Epoch-3 LoRA。
3. 在符合要求的双 GPU 环境中按照精简 ZIP 内 `README.md` 执行独立推理。
4. 权限审核完成后，可单独建立公开的**精简代码仓库**供下载；原始研究档案是否公开另行决定。正式发版前不要把私有研究档案库整体切换为 Public。

冻结实验统计结果与新照片推理运行记录分别保存、分别说明。
